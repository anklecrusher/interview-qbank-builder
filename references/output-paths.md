# 输出路径规范

## 默认规则

题库应保存到：

    <题库根目录>/<公司名称>/<公司名称>-<岗位名称>-面试题库.md

示例：

    E:\desktop\personal\秋招\面经加问题库\示例公司\示例公司-电气工程师-面试题库.md

## 写入前检查

- 必须确认公司名称和岗位名称；
- 题库根目录缺失时，优先询问，不要猜测个人路径；
- 先读取同公司目录中的已有题库；
- 不删除旧文件；
- 用户未明确要求时，不覆盖同名文件；
- 同一岗位更新时，可追加版本说明或生成 v2 文件；
- 写入后使用目录列表和文件读回验证路径及内容。

## 推荐文件布局

    面经加问题库/
    └── 公司名称/
        ├── 公司名称-岗位名称-面试题库.md
        ├── 公司名称-岗位名称-小红书面经摘要.md  # 仅在用户明确开启小红书时生成
        └── 公司名称-岗位名称-面试复盘.md        # 面试后按需生成

小红书未开启时，题库中应明确写明“小红书检索：未开启”，不得创建伪造的面经摘要。
