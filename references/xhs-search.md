# 小红书检索操作参考

本文件只描述本 Skill 在生成题库阶段如何通过 agent-reach 使用小红书公开内容，不保存任何 Cookie、Token、完整搜索 JSON 或个人登录信息。

## 认证门禁

xhs status
xhs whoami

如果返回未认证、Session expired、No a1 cookie found、Cookie 缺失、浏览器会话不可用或命令未配置：

1. 停止题库生成；
2. 告知用户先完成浏览器或扫码登录；
3. 不索取、不记录、不回显 Cookie、Token 或本地存储内容；
4. 用户回复“已登录”后重新执行 xhs status 和 xhs whoami；
5. 两项通过后才开始搜索。

## 检索命令

xhs search "公司名 岗位名 面试"
xhs search "岗位名 面试题"
xhs search "公司名 面经"
xhs search "行业方向 岗位名 高频题"

需要阅读详情时，只使用搜索结果提供的 URL 或带上下文的 ID：

xhs read "搜索结果中的 URL 或 ID"
xhs comments "搜索结果中的 URL 或 ID"

不要用裸 note_id 拼接请求。检索应保持低频，通常每次请求间隔 2~3 秒；遇到验证码或风控时停止批量操作。

## 摘要字段

每次题库生成应保留以下摘要字段：查询词、代表性笔记标题和 URL（若工具提供）、多条样本重复出现的高频题型、仅单条内容出现的线索、面试轮次与技术深度信号、登录状态、搜索覆盖范围和失败限制。

小红书材料只是公开面经样本，不是事实来源，也不能替代候选人简历、工作日志和知识库。
